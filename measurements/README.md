# Measurements

Instrument: GW Instek GDS-2104A 100 MHz digital storage oscilloscope, plus a digital multimeter. Audio source: MacBook headphone output (0.5 V RMS at full volume).

| File | Contents |
|---|---|
| [dc_operating_point.csv](dc_operating_point.csv) | Supply voltages, receiver current, laser bias/peak current, laser V_f |
| [frequency_response.csv](frequency_response.csv) | 40 Hz – 13 kHz sweep observations, linked to scope captures |
| [simulated_vs_measured.csv](simulated_vs_measured.csv) | PSpice predictions vs hardware measurements |
| [detector_comparison.csv](detector_comparison.csv) | Phototransistor vs bare photodiode vs shrouded photodiode |

Oscilloscope captures are in [`../images/measurements/`](../images/measurements/).
